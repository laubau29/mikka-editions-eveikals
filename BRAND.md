# Mikka Editions — colour palette and fonts

Taken from the shop's own code (`:root` block at the top of `index.html`). Change a main colour there and it changes everywhere.

## Main colours

| Name | Look | HEX | RGB | Used for |
|---|---|---|---|---|
| Paper | Cream | `#F2E9D8` | 242, 233, 216 | Page background, light text on dark areas |
| Ink | Near-black | `#252622` | 37, 38, 34 | Text, buttons, dark bands |
| Brick | Red-brown | `#AE4C35` | 174, 76, 53 | Accent: links, "Print it yourself.", cart badge |
| Fjord | Slate blue-grey | `#4C6169` | 76, 97, 105 | Secondary accent, some headings |
| Ochre | Mustard | `#C99D39` | 201, 157, 57 | Accent in illustrations and highlights |

## Supporting colours

| Name | HEX | Used for |
|---|---|---|
| Soft grey | `#ECECEB` | Box behind product pictures on shop pages |
| Fjord, lighter | `#58717A` | Inside the edition illustrations |
| Fjord, darker | `#4A5C63` | One small accent |
| Ink, faint | `rgba(37, 38, 34, 0.12 to 0.18)` | Thin lines, borders, dividers |

## Fonts

- Headings: Georgia, serif
- Body text: Arial, sans-serif

## Rules we agreed on

- No yellow tint over product photos (it looked ugly). Neutral soft grey behind Printful pictures on shop pages.
- All T-shirts use the same framed card style as the other products.
